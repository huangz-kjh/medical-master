# 医疗影像智能分析与预约管理系统

## 项目简介

本系统是一个基于 Flask 框架开发的现代化医疗管理平台，集成了深度学习医学影像分析、智能诊断、医患沟通、预约管理、患者全周期管理等功能。系统支持多角色（患者、医生、管理员）操作，实现了从预约、诊疗、随访到报告的全流程闭环管理。

## 技术架构

- **后端框架**：Flask 2.x、SQLAlchemy、Flask-Session
- **数据库**：MySQL 5.7+
- **深度学习**：PyTorch 2.x
- **前端**：Vue.js、Element UI
- **图像处理**：SimpleITK、OpenCV、Pillow
- **部署环境**：支持 Linux/Windows，推荐使用虚拟环境

## API 接口文档

### 认证相关
- POST `/api/auth/login` - 用户登录
- POST `/api/auth/register` - 用户注册
- GET `/api/auth/logout` - 用户登出
- GET `/api/auth/profile` - 获取用户信息

### 预约管理
- GET `/api/appointments` - 获取预约列表
- POST `/api/appointments` - 创建预约
- GET `/api/appointments/{id}` - 获取预约详情
- PUT `/api/appointments/{id}` - 更新预约状态
- DELETE `/api/appointments/{id}` - 取消预约

### 医学影像
- POST `/api/images/upload` - 上传医学影像
- GET `/api/images/{id}` - 获取影像详情
- POST `/api/images/{id}/analyze` - 执行影像分析
- GET `/api/images/{id}/report` - 获取分析报告

### 用户管理
- GET `/api/users` - 获取用户列表
- POST `/api/users` - 创建新用户
- PUT `/api/users/{id}` - 更新用户信息
- DELETE `/api/users/{id}` - 删除用户
- POST `/api/users/{id}/reset-password` - 重置密码

### 系统管理
- GET `/api/system/config` - 获取系统配置
- PUT `/api/system/config` - 更新系统配置
- GET `/api/system/logs` - 获取系统日志
- POST `/api/system/backup` - 创建系统备份

医疗预约系统流程分析
1. 患者预约流程
发起预约:
患者在appointment.html页面填写预约表单，包括预约类型、科室、医生、日期、时间段和症状描述
系统通过API接口/api/appointments创建预约记录，默认状态为"待确认"
提交后显示成功提示，并自动刷新预约列表
查看预约:
患者可以在"历史预约"部分查看所有预约记录
预约状态包括：待确认（黄色）、已确认（蓝色）、已完成（绿色）和已取消（红色）
每个预约都显示详细信息包括预约编号、类型、科室、医生、日期时间和状态
取消预约:
患者可以取消"待确认"或"已确认"状态的预约
通过API接口/api/appointments/{id}/cancel完成取消操作
查看检查报告:
当预约状态为"已完成"时，患者可以查看相关的检查报告
点击查看报告按钮跳转到报告详情页面
2. 医生预约管理流程
查看待处理预约:
医生在doctor_appointments.html页面查看"待确认预约"列表
每个预约卡片显示患者信息、预约详情和症状描述
预约操作:
确认预约：医生确认预约请求，预约状态变为"已确认"
拒绝预约：医生拒绝预约请求，预约状态变为"已取消"
查看病例：跳转到患者详情页查看病历
已确认预约管理:
查看所有"已确认"状态的预约
标记完成：医生完成预约后，状态变为"已完成"
对于特定类型的预约（放射科或神经科的常规检查、专科预约或随访），系统会自动创建检查报告记录
历史预约记录:
查看所有"已完成"或"已取消"的预约历史
完成的预约可以创建随访预约、查看病例或查看检查报告
创建随访预约:
医生可以为患者创建随访预约
指定随访类型、建议日期和随访说明
系统创建一个状态为"已确认"的新预约
3. 检查报告管理流程
报告列表查看:
医生和患者都可以查看报告列表，但权限不同
患者只能查看自己的报告
医生可以查看所有负责患者的报告
报告详情查看:
点击查看按钮可以查看报告详情
报告详情包括基础信息、分析结果、结论和健康建议
对于有图像的报告，可以查看相关医学影像
医生添加分析:
医生可以为"待分析"状态的报告添加分析结果、结论和健康建议
提交分析后，报告状态变为"已完成"
患者可以查看已完成的报告结果
报告编辑与打印:
医生可以编辑已有报告
医生可以打印报告供存档或给患者
数据流通与状态变化
预约状态流转:
初始状态：患者创建预约时为"待确认"
医生确认预约：状态变为"已确认"
医生完成预约：状态变为"已完成"
患者或医生取消预约：状态变为"已取消"
报告系统与预约系统的集成:
医生完成某些类型的预约后自动创建检查报告
患者可以通过预约记录查看相关的检查报告
患者可以通过报告页面直接预约新的检查
随访逻辑:
医生可以根据患者情况和检查结果创建随访预约
随访预约会记录在患者的病例中，成为医疗记录的一部分"# medical-master"
